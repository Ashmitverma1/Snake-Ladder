# 🎲 Snake and Ladder Game (C Version)

This is a simple **Snake and Ladder** game for two players, implemented in the C programming language. Players take turns to roll a dice and move forward on the board. If a player lands on a ladder, they climb up; if they land on a snake, they slide down. The first player to reach **position 100** wins!

---

## 🧩 Features

- Two-player turn-based gameplay
- Random dice roll simulation
- Snakes and ladders logic
- Victory condition when a player reaches exactly 100
- Input via `Enter` key for interactive play

---

## 🚀 How to Run

### 1. Compile the Code

Make sure you have a C compiler (like `gcc`) installed. Then run:

```bash
gcc snake_ladder.c -o snake_ladder
